# Sneaky Surprise website preview

This is a static, Vercel-ready website preview. Open `index.html` locally, or deploy this folder as a static site.

Before publishing it on the live domain, add or confirm:

- real WhatsApp, Instagram, email, and delivery-platform links;
- the approved logo and brand story;
- actual pop-up, event, and collaboration details; and
- whether to keep the generated hero visual or replace it with a supplied brand/product photo.

The site has no checkout or form backend yet, so it does not collect customer data. Confirm the menu details before launch.
